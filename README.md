 ## Ben Watson

  Engineer working on the reliability of AI systems — evals, guardrails, and the
  question of how you know an agent's output is actually right.

  **Currently** at [Tenzo](https://gotenzo.com), where I designed and shipped an
  autonomous QA-and-auto-fix system: customer-reported data issues get triaged,
  investigated overnight by a Claude agent reading production data and our monorepo,
  and — where the diagnosis clears a set of quality gates — come back as a fix on a
  branch with a draft PR opened for review.

  The interesting part isn't getting an agent to produce output. It's knowing when
  it's wrong. That work has meant a formal failure-mode taxonomy built from real
  incidents, eleven runtime guardrails each tied to one of them, an adjudicator
  second pass, a calibration ledger, and a deterministic classifier that decides
  what's safe to run unattended.

  **Also** — two MCP servers, a Claude Code skill library the team uses daily, and
  three years of ETL bug investigation across ~18 third-party integrations before
  any of the agent work.

  Most of what I build is in private repos. Happy to talk about any of it.
